# Änderungen v1.7.21-r9

- Jede freigeschaltete Set-Gegenstandskarte besitzt nun die Aktion „Set-Gegenstandskarte entfernen“.
- Die Aktion nimmt die Freischaltung zurück, entfernt sämtliche zugehörigen Inventarpositionen und verbirgt die Karte wieder.
- Bei Begleiter- und Reittierkarten wird der automatisch angelegte, dauerhaft verknüpfte Reiter gemeinsam entfernt.
- Vor der vollständigen Entfernung erscheint eine eindeutige Sicherheitsabfrage.
- Eine entfernte Karte kann später mit ihrem vierstelligen Code erneut freigeschaltet werden.
