# Eberos v1.8.23 – Standard-Itembilder und Kartenbrücke

- Alle 203 Standarditems besitzen eine eigene Illustration im einheitlichen Eberos-Stil.
- Die vollständige Itemliste zeigt die Bilder als zugängliche, nachgeladene Miniaturen.
- Katalogeinträge tragen einen stabilen Bildpfad und die SHA-256-Prüfsumme des Motivs.
- Das Bildmanifest bindet jedes Motiv eindeutig an Katalog-ID, Katalogversion und reproduzierbaren Prompt.
- Die Bilder können über das Standard-Item-Template im Eberos Layout Studio als Karten gerendert werden.
- Builder-Schema 45; Regelstand 17.
